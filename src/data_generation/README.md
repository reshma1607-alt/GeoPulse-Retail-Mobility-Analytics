# GPS Data Generation

This module generates synthetic anonymized mobile GPS data for
the GeoPulse project.

## Required Data

The GPS dataset will contain:

- DeviceID
- Latitude
- Longitude
- Timestamp

## Purpose

The generated data will represent movement of mobile devices
through different areas of a city.

The data will later be used for:

- Footfall analysis
- Store catchment analysis
- Spatial joins
- Visitor analysis
- Store cannibalization analysis
